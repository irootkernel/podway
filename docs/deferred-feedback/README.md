# Deferred Feedback

This register tracks small review findings that are valid but intentionally not
handled in the originating change. Epic-sized findings belong in [TODO](../todo/).

## Open

Candidate grouping leaves feedback open. The linked candidate owns each grouped
entry's detailed finding, original deferral reason and revisit condition; this
register retains its ID, source and summary. A candidate link is not roadmap
promotion or implementation evidence. Independent entries retain full details.

Follow the [TODO partial-promotion and retirement lifecycle](../todo/README.md#lifecycle)
when selecting part of a candidate: only selected entries receive actual roadmap
mapping, and every remaining Open entry keeps one detailed owner before any
candidate or dossier is converted or deleted. Resolved-by-promotion closes the
deferral only; the roadmap records implementation and acceptance.
