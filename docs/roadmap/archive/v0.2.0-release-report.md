## Qualification and publication

The exact clean source commit passed `make dist` through
`gaori --json run dist`. The first clean run exposed five release-only
all-target Clippy failures and stopped before packaging. Commit `98acf3a`
applied only semantics-preserving test idioms; `make lint-all`, an independent
review, and a two-role Mulgae review passed before the complete clean
distribution gate was rerun. The final gate passed with exit code 0 in
`.gaori/runs/standalone/20260812T114931/dist.summary.md`, including formatting,
all-target Clippy with warnings denied, unit/integration/E2E tests, contract
sentinels, pinned bounded fuzz targets, release-profile compilation, packaged
conformance, handoff generation, and final bundle verification.

Packaged conformance passed these scenarios:

- `aut_t_id_custom_procedure_survives_restart_and_completes_the_fenced_lifecycle`;
- `aut_t_id_and_recon_reject_conflicts_and_recover_an_admitted_timeout`;
- `aut_t_recon_response_loss_is_reconciled_by_lookup_and_exact_replay`; and
- `aut_t_v2_public_admission_survives_restart_and_completes_rework_and_goal_closeout`.

Repository release immutability reported `enabled=true` before the draft was
created. The annotated tag was pushed atomically with `main`. The draft contained
exactly the four qualified artifacts. Every host-reported asset name, size, and
digest matched the local qualified bytes, and every draft asset was downloaded by
numeric asset ID to `/tmp/podway-v020-draft.Lrs8Hj`. The independent
`tools/verify_release_bundle.py verify` command passed before publication.

that the archive's embedded `RELEASE_NOTES.md` intentionally preserves its
qualification-time prepublication state; neither the source candidate nor any of
the four qualified artifact bytes was changed or rebuilt during V2REL-007.

## Remaining limitations

- The release supports native Apple Silicon macOS only.
- The binaries are unsigned and notarization was not attempted.
- The daemon is a per-user LaunchAgent and starts after GUI login.
- Podway is a same-user local tool and is not a multi-user access-control boundary.
- Dolgorae integration is specified by the handoff; downstream adoption remains a
  separate repository decision.
