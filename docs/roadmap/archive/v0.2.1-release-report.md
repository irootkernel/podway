the sole supported authoring and runtime model and preserves the explicit
fail-closed recovery boundary for legacy Procedure v1 state.

## Qualification and publication

The exact clean source commit passed the complete `make dist` release gate
through `gaori --json run dist` with exit code 0. The final evidence is stored
locally at `.gaori/runs/standalone/20260814T201004/dist.summary.md`; its artifact
status is `passed`, its extractor status is `no_match`, and it reports no
failures. Independent bundle verification also returned `ok: true`.

Two release-only gaps were corrected before the final clean run. Commit
`1729206` replaced obsolete single-variant test matches exposed by all-target
Clippy. Commit `8c1bb5d` replaced a deleted Procedure v1 example dependency in
the fuzz corpus with a current Procedure v2 request seed. The final gate then
passed the development gate, all-target linting, four bounded fuzz targets,
release builds, packaged conformance, qualification, Dolgorae handoff, and
bundle verification.

The annotated tag and `main` were pushed atomically. A draft GitHub release was
created with exactly the four qualified artifacts. Each draft asset was
downloaded by numeric asset ID into a fresh directory, its SHA-256 was compared
with the local qualified byte, and the independent bundle verifier passed. The
release was then published with immutable releases enabled. All four public
assets were downloaded again by numeric asset ID into another fresh directory;
their identities matched the table above and the bundle verifier passed again.

## Remaining limitations

- The release supports native Apple Silicon macOS only.
- The binaries are unsigned and notarization was not attempted.
- The daemon is a per-user LaunchAgent and starts after GUI login.
- Podway remains a same-user local tool rather than a multi-user security boundary.
- The local installed v0.2.0 daemon was restored after qualification; installing
  or activating v0.2.1 was outside this release operation.
