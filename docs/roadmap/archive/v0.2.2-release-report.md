## Qualification, publication, and installation

The exact clean source commit passed the complete `make dist` gate through Gaori.
The gate included `make test`, all-target linting, bounded fuzzing, release builds,
isolated packaged conformance, Dolgorae handoff generation, and final bundle
verification. The installed v0.2.1 production daemon remained live throughout.

The annotated tag and `main` were pushed atomically. Exactly four draft assets
were downloaded by numeric asset ID and matched the qualified local digests before
publication. The immutable public assets were downloaded and independently
verified again after publication without rebuilding them. The prior v0.2.1 release
remained immutable with unchanged asset identities.

Installing the public archive exposed a LaunchAgent refresh defect: the initial
`daemon install` stopped after publishing prepared service metadata, and ordinary
endpoint resolution then blocked the documented retry. The installation was
completed with the supported explicit socket override, after which the v0.2.2
daemon was reachable with the published identity. This behavior is the direct
subject of the v0.2.3 patch.

## Remaining limitations

- The release supports native Apple Silicon macOS only.
- The binaries are unsigned and notarization was not attempted.
- The daemon is a per-user LaunchAgent and starts after GUI login.
- Podway remains a same-user local tool rather than a multi-user security boundary.
- No MCP server or MCP transport is included.
