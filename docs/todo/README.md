# TODO Candidates

This directory holds work candidates that are not yet adopted into the active
roadmap. One `TODO-*.md` file represents one candidate and contains:

1. Context
2. Goal
3. Non-goals
4. Rough Scope
5. Open Decisions
6. Roadmap Promotion Conditions
7. References

Do not put task tables, implementation order, completion evidence, or normative
behavior here. Move accepted behavior to specifications and adopted work to the
roadmap, then remove the candidate file.

There are currently no open TODO candidates.
